# 📊 Sales Data Exploration and Visualization for E-Commerce using Power BI

## 📌 Project Overview

This project consists of three interactive Power BI dashboards developed using an E-Commerce Sales dataset. The dashboards provide a comprehensive analysis of sales performance, customer purchasing behavior, product performance, and future sales forecasting.

The primary objective of this project is to transform raw sales data into meaningful business insights that support data-driven decision-making.

## 🚀 Dashboards Included

### 1. 📊 E-Commerce Sales Dashboard

An interactive dashboard for analyzing sales and profit across regions, products, customers, shipping methods, payment modes, and time.

Provides an overview of:

- Total Sales
- Total Orders
- Total Profit
- Average Ship Days
- Sales by Region and State
- Sales by Category & Sub-Category
- Sales by Customer Segment
- Sales by Payment Mode
- Sales by Ship Mode
- Monthly Sales Trends

### 2. 🛒 Market Basket Analysis Dashboard

Analyzes product frequency to identify products that occur frequently in transactions.

This analysis can support:

- Product Performance Analysis
- Inventory Planning
- Cross-Selling
- Product Bundling

### 3. 📈 Sales Forecast Dashboard

Uses Power BI's forecasting feature to analyze historical sales and forecast sales for the next **15 days**.

Includes:

- Historical Sales Trends
- 15-Day Sales Forecast
- Forecast Confidence Interval
- Interactive Date Analysis

## 📂 Dataset

The dataset contains E-Commerce transactions from **2019–2020**, including:

- Order Details
- Product Information
- Category & Sub-Category
- Sales & Profit
- Quantity
- Region, State & City
- Customer Segment
- Payment Mode
- Ship Mode
- Order Date

## 📈 Key Insights

- **Office Supplies** is one of the leading sales categories.
- **Standard Class** has the highest sales among the displayed shipping modes.
- Sales performance varies across regions and states.
- Customer segments can be compared to understand their contribution to sales.
- Monthly trends help identify changes in sales performance over time.
- Product frequency analysis highlights frequently occurring products.
- The forecasting dashboard provides a **15-day sales prediction** based on historical trends.
